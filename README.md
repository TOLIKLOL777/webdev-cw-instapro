# Instapro

MVP социальной сети для обмена фотографиями

**Интеграция верстки списка постов с API**
Из API сервера берутся все посты и они отображаются на сайте путем рендера

**Реализация страницы добавления поста**
Сделал страницу для добавления нового поста, на странице находиться форма с кнопкой загрузки фотографии и описанием, после отправки происходит POST запрос на сервер и новый пост отображается на сайте

**Реализация страницы с постами отдельного пользователя**
При нажатии на аватар или имя пользователя появляется страничца с постами пользователя которого вы выбрали

**Реализация функции лайков**
При нажатии на кнопку лайка происходит API запрос и пост лайкается или дизлайкается соответственно, лайкать посты может только авторизованный пользователь
